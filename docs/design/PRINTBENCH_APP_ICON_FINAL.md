# 135er-PRINTBENCH FINAL APP ICON

Status: **VERBINDLICH / FINAL**
Freigabe: 2026-10-15

Das vom Nutzer als **Icon 3** ausgewählte Hero-Icon ist das verbindliche App-Icon von **135er-PRINTBENCH**.

## Verwendung

Das Icon ist kein separates Benutzer-Download-Artefakt. Es gehört in den Produkt-Build und wird beim Windows-Build automatisch für folgende Stellen verwendet:

- Windows EXE-Ressource
- Installer/Setup
- Startmenü
- Desktop-Verknüpfung
- Taskleiste/Fenstericon
- Deinstallations-/Apps-&-Features-Eintrag

## Zielpfade im Repo

Beim nächsten Windows-Build werden die finalen Binärassets unter diesen festen Pfaden eingebunden:

- `assets/branding/PRINTBENCH_AppIcon.ico`
- `assets/branding/PRINTBENCH_AppIcon_MASTER_1024.png`

Die `.ico`-Datei enthält die Windows-Größen 256, 128, 64, 48, 32 und 16 px. Das 1024×1024-PNG ist die verlustfreie Masterquelle für weitere Ableitungen.

## Verbindliche Regel

Kein anderes Orca-/Bambu-/Default-Icon darf im finalen 135er-PRINTBENCH-Installer oder in der ausgelieferten EXE sichtbar bleiben. Installer und EXE müssen vor Freigabe gegen diesen Branding-Contract geprüft werden.
